# 공식 배너 Masthead

공식 배너는 사용자가 대한민국 정부 조직 및 관련 기관에서 운영 및 관리하는 디지털 정부서비스임을 식별할 수 있도록 제공하는 정보 배너이다.

## 기본

페이지 맨 위 요소에 `krdsMasthead`를 붙이고 문구를 내용으로 넣습니다. KRDS 스타일이 id `krds-masthead`를 기준으로 적용되므로 `id`는 기본값 그대로 둡니다.
